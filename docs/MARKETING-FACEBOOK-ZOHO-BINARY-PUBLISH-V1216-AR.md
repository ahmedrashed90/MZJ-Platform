# تصحيح نشر صور Zoho إلى Facebook — V1216

## المشكلة
كان مسار النشر يرسل رابط Zoho الخاص إلى Facebook في حقل `url`. الرابط يحتاج صلاحية Zoho، ولذلك Facebook لم يستلم صورة فعلية وأعاد الخطأ `Missing or invalid image file`.

## التنفيذ
- تنزيل محتوى الصورة من Zoho WorkDrive داخل Backend باستخدام OAuth ومسار تنزيل الملفات الخاص بمركز بيانات السعودية.
- إرسال الصورة نفسها إلى Graph API بصيغة `multipart/form-data` في حقل `source`.
- الصورة الواحدة تُرسل مباشرة إلى `/{pageId}/photos`.
- الكاروسيل يرفع كل صورة بالترتيب كصورة غير منشورة، ثم ينشئ المنشور باستخدام `attached_media`.
- صورة Facebook Story تستخدم نفس رفع الملف الفعلي قبل إنشاء Story.

## خارج النطاق
لم يتغير إنشاء الحملات أو الأجندات أو تجهيز النشر أو رفع الملف النهائي أو تدفق Instagram.
