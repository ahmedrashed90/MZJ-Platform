# MZJ Owners Community — Rewards Catalog v1209

## النطاق

هذا الإصدار مبني مباشرة على السورس المعتمد v1.20.8 المرفق، والتعديل محصور داخل MZJ Owners Community وكتالوج المكافآت وCommerce API فقط. لا يوجد أي تعديل في CRM أو Tracking أو Operations أو Marketing أو Next ERP أو أي نظام آخر.

## التعديلات

- إضافة زر **حذف** داخل بطاقة المكافأة. الحذف الفعلي مسموح فقط للمكافأة التي ليس لها استبدالات أو استخدامات شراء سابقة، للحفاظ على سجل العمليات.
- إضافة اختيار مستقل: **متاحة للعميل القديم عند استخدام كود الدعوة في طلب الشراء**.
- اختيار العميل الجديد الحالي يظل كما هو. العميل الجديد يستطيع رؤية مكافآت العميل الجديد ومكافآت العميل القديم، بينما العميل القديم يرى مكافآت العميل القديم فقط.
- مكافأة الخصم المخصصة للموقع أصبحت تدعم طريقتين:
  - **قيمة خصم** بالريال.
  - **نسبة خصم** من 0 إلى 100%.
- Commerce API يعيد الآن `customerKind` وقيم الخصم المنظمة: `discountType`, `discountValue`, `discountAmount`, `discountPercent`.
- العميل القديم لا يتم إدخاله في Referral/CRM جديد عند استخدام مكافأة العميل القديم؛ فلو الإحالة الحالي للعميل الجديد يظل كما هو.

## توافق API

الحقول القديمة مثل `discountAmount` ما زالت موجودة للخصم الثابت. عند اختيار نسبة خصم تكون `discountAmount = 0` ويعاد أيضًا `discountPercent` و`discountValue` حتى يحسب البلجن النسبة على السعر المحدد لديه.
