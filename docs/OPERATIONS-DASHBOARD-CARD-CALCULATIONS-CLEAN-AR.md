# توحيد حساب كروت مخزون العمليات

تم تنفيذ التعديل داخل السورس الأساسي للمنصة، مع استخدام السيستم القديم كمرجع لمعادلات الحساب والعرض فقط، دون نقل أي مسارات أو قواعد بيانات أو تنفيذ قديم.

## المعادلات المعتمدة

- **الإجمالي الفعلي:** جميع سيارات المخزون النشط غير المؤرشف، بعد استبعاد حالتي `مباع تحت التسليم` و`مباع تم التسليم`.
- **متاح للبيع:** السيارات التي حالتها الفعلية `متاح للبيع` فقط.
- **حجز:** السيارات التي حالتها الفعلية `حجز` فقط.
- **بها ملاحظات:** السيارات التي حالتها الفعلية `بها ملاحظات` فقط، وليس أي سيارة تحتوي على نص ملاحظة وهي في حالة أخرى.
- **مباع تحت التسليم:** السيارات النشطة التي حالتها `مباع تحت التسليم` فقط.
- **مباع تم التسليم:** السيارات التي ما زالت ضمن المخزون النشط وحالتها `مباع تم التسليم` فقط؛ السيارات المؤرشفة لا تظهر في كروت المخزون الحالي.
- **الوكالة:** نفس معادلة الإجمالي الفعلي مع قصر المكان على الوكالة.

## ضمان التطابق

- تم إنشاء مصدر حساب واحد داخل الـBackend لكل مؤشرات المخزون.
- كارت إجمالي المخزون، وكروت المواقع، ونافذة عرض التفاصيل تستخدم المصدر نفسه.
- كل رقم في الكارت يساوي عدد النتائج التي تظهر عند فتحه بنفس المكان والحالة والصلاحيات.
- الحسابات الحالية لا تتأثر بفلتر تاريخ الداش بورد لأنها تمثل لقطة المخزون الحالي.
- لم يتم تعديل مسارات الأنظمة أو دورة الموافقات أو الطلبات أو تصميم الداش بورد.

## قاعدة البيانات

لا توجد Migration أو تعديلات قاعدة بيانات مطلوبة.
