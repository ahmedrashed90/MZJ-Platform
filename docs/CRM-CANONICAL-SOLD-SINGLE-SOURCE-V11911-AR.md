# CRM Canonical Sold Single Source - v1.19.11

تمت إعادة بناء حساب عدد المباع بحيث يكون `crm.sales_transactions` هو المصدر الوحيد للحقيقة.

- قائمة العملاء لا تجمع NEXT ERP مرة ثانية فوق Sales Transaction.
- تقارير العملاء/المناديب لا تجمع ERP + Transactions.
- ملخص العميل `sold_quantity` و`sold_at` يتجدد من المعاملات النشطة فقط.
- داشبورد CRM والداشبورد الموحد يستخدمان المعاملات النشطة فقط للمبيعات.
- سجل المبيعات يظل يعرض نفس المعاملة Canonical، لذلك كل الشاشات تتطابق في الكمية.
- لا تغيير في مطابقة العميل بالجوال أو تحويل الحالة التلقائي من NEXT ERP أو التوزيع أو المحادثات أو العمليات.

يوجد سكربت اختياري لمرة واحدة:
`database/reconcile-crm-lead-sales-snapshot-from-transactions.sql`
لمزامنة القيم القديمة في `crm.leads` مع المعاملات Canonical بدون حذف أو إنشاء أي مبيعات.
