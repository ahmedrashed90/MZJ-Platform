# إعادة بناء النشر اليدوي ومتعدد الصور — V1229

## النطاق
أُعيد بناء تبويب **النشر اليدوي** داخل تجهيز النشر على المصدر الأساسي، دون إضافة طبقة واجهة أو مسار نشر موازٍ فوق المنطق السابق.

## التدفق الجديد
1. يختار المستخدم حملة أو أجندة من السجلات التي تقع داخل نطاق صلاحياته.
2. يختار **نوع الكرييتيف** من الأنواع المفعلة في إعدادات النظام، بدل اختيار كرييتيف أو تاسك موجود مسبقًا داخل الحملة أو الأجندة.
3. يختار ملفًا أو عدة ملفات مباشرة من جهازه، ويمكنه ترتيب الصور أو حذفها قبل الحفظ.
4. يحدد المنصات وأنواع النشر والموعد والكابشن والهاشتاج وإعدادات YouTube عند الحاجة.
5. ينشئ الخادم كرييتيفًا جديدًا وسجل نشر يدويًا معزولًا، ثم تُرفع الملفات عبر مسار Zoho WorkDrive الحالي المعتمد.
6. عند فشل الرفع أو إلغائه، تُحذف مسودة النشر اليدوي وقوائم النشر المرتبطة بها بدل ترك سجلات ناقصة.

## تعدد الصور
- **بوست صور:** يدعم أكثر من صورة، وينفذ كمنشور متعدد الصور أو Carousel واحد حسب المنصة.
- **ستوري:** يدعم أكثر من صورة، وتُنشر الصور كإطارات Story مستقلة حسب ترتيبها داخل القائمة.
- الفيديو والريل وShorts يظلون ملف فيديو واحدًا فقط.
- ترتيب ملفات النشر اليدوي يُحفظ من واجهة الاختيار إلى مجموعة الملفات النهائية ثم إلى الناشر.

## النشر التلقائي واليدوي
كلا المسارين يستخدمان نفس:
- تطبيع المنصات وأنواع النشر.
- التحقق من توافق نوع الملف مع نوع النشر.
- إنشاء مجموعات جدول النشر.
- ناشري Facebook وInstagram ومتعدد الصور الحاليين.

لم يُنشأ Endpoint نشر مكرر، ولم يُغيّر منطق النشر الفعلي الذي تم إصلاحه في V1228 لرفع فيديو Instagram القابل للاستئناف.

## عزل سجلات النشر اليدوي
يُنشأ سجل داخلي من النوع `manual_publish` لاستخدامه في ربط الملفات وجدول النشر فقط. هذا النوع:
- يظهر داخل تجهيز النشر.
- لا يظهر كتاسك موظف عادي.
- لا يدخل في نسبة تقدم الحملة أو الأجندة.
- لا يغيّر فلو Task Template أو التاسكات التنفيذية.

## التعديل بعد الإنشاء
- يظهر سجل النشر اليدوي داخل قائمة تجهيز النشر بوسم **نشر يدوي** بدل اعتباره تاسكًا تنفيذيًا.
- يمكن تعديل موعد النشر والمنصات وأنواع النشر والكابشن والهاشتاج لاحقًا من نفس نافذة التعديل ونفس خدمة جدول النشر.
- مسار إرفاق الملف الفردي القديم لا يقبل سجلات `manual_publish`؛ رفعها يمر فقط عبر مجموعة الملفات المرتبة المعتمدة.
