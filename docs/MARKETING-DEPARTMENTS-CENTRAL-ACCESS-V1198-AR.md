# إصلاح ربط أقسام التسويق — v1.19.8

- أصبح `core.departments` هو المعرّف المركزي لأقسام التسويق، مع نفس UUID المستخدم داخل التسويق والمستخدمين والصلاحيات.
- أصبحت عضوية المستخدمين تُحفظ وتُقرأ حصريًا من `core.user_system_departments` للنظام `marketing`.
- تتم مزامنة جدول `core.user_departments` التجميعي دون حذف أقسام الأنظمة الأخرى ودون تغيير القسم الأساسي.
- يتم ترحيل عضويات `marketing.department_users` القديمة مرة واحدة ثم حذف الجدول القديم.
- قائمة اختيار يوزرات القسم تعرض كل الحسابات الفعالة غير المحذوفة، وتدعم البحث والاختيار المتعدد.
- إنشاء الحملة والأجندة يقرآن يوزرات كل قسم من الأقسام المسموحة الفعلية، لذلك يظهر المستخدم في كل الأقسام المرتبط بها.
- تمت إعادة تنظيم صفحة الإعدادات بقائمة جانبية قابلة للبحث، مجموعات قابلة للفتح والإغلاق، ورؤوس وأزرار حفظ ثابتة أثناء التمرير.
- لم يتم تعديل `role_id` أو دمج/حذف الأدوار أو تغيير مفاتيح الصلاحيات.
