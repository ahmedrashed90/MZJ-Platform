# محرك البحث داخل داش بورد التسويق — 8 نوفمبر 2026

## النطاق

استبدال بحث الداش بورد البسيط بنتائج مجمعة تحت خانة **«بحث...»** دون إضافة عنوان «بحث شامل في الداش بورد» ودون تغيير كروت قسم التنفيذ وقسم النشر.

## السلوك

- البحث أثناء الكتابة، بالكلمة أو بأي جزء منها؛ لا يشترط الاسم الكامل، مع توحيد أشكال الهمزة والتشكيل والأرقام العربية/الإنجليزية.
- يشمل التاسكات (اسم التاسك، الرقم، النوع، المنفذون المسموح بمشاهدتهم، أسماء الأفكار ووصفها، الحالة)، والمنشورات (المنصة، نوع النشر، المنتج، الفكرة، الاسم، الرقم، المنفذ، الكابشن والهاشتاق والحالة)، والأجندات والحملات.
- المنشورات نتيجة مستقلة لكل صف نشر؛ البحث عن منصة يُظهر منشوراتها فقط ولا يسحب كل صفوف الأجندة لمجرد وجودها في الأجندة نفسها.
- عرض التاريخ المخطط للنشر بشكل منفصل عن تاريخ النشر الفعلي، مع إظهار «غير مسجل» عندما يوجد رابط بلا تاريخ فعلي ثابت. تظهر فترات الحملات والأجندات والتسليم حسب سجلات النظام، ولا يتم اختلاق نهاية لفترة غير منتهية.
- يقبل البحث بصيغ التواريخ YYYY/MM/DD و D/M/YYYY و YYYY/MM و M/YYYY، مع الشرطة أو الشرطة المائلة، ويمنع خلط 8/11 بيوم 18/11.
- النتائج القادمة أولًا حسب قرب موعدها ثم أحدث النتائج الماضية؛ زر «عرض المزيد» داخل كل مجموعة، وفتح التفاصيل الأصلية لكل نوع.
- يبقى الداش بورد الأصلي ظاهرًا كما هو، ولا يحذف البحث أو يعدّل بيانات أي منشور أو تاسك.
- يعتمد على استجابة الداش بورد المقيّدة بصلاحيات المستخدم؛ تمت إضافة أسماء المنفذين والأفكار والتواريخ إلى نفس استعلام التاسكات، من عناصرها الظاهرة للمستخدم فقط، من دون API جديد أو SQL migration.
