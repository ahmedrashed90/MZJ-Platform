# تحديث واجهات الكرييتيف والتصدير V1.22.5

تم التنفيذ على السورس الأساسي مباشرة، ويشمل:

- إعادة تصميم زر إضافة الكرييتيف وزر الأرشفة ونافذة إضافة/تعديل الكرييتيف.
- تحويل اختيار الكرييتيف في ميزانية الحملة وجدول النشر إلى اختيار متعدد.
- حفظ ربط بند الميزانية بأكثر من كرييتيف من خلال جدول علاقات مستقل، مع الحفاظ على التوافق مع البيانات القديمة.
- إنشاء جدول نشر لكل كرييتيف محدد في اليوم نفسه.
- إعادة تصميم اختيار المنصات وأنواع النشر داخل إنشاء الأجندة.
- إعادة بناء مولد XLSX لإنتاج ملفات OpenXML سليمة، RTL، وبها البيانات الفعلية، مع تنظيف الحروف غير الصالحة داخل XML.
- دعم عرض وربط الميزانية المشتركة في تفاصيل الحملة وتقارير PDF.

لا يتطلب التحديث تشغيل SQL يدوي؛ تهيئة مخطط التسويق تنشئ علاقة الميزانية الجديدة وتملأ البيانات القديمة تلقائيًا.
