# إعدادات نشر YouTube — V1222

## نطاق التنفيذ

تم التنفيذ مباشرة داخل سورس المنصة الحالي، بدون نقل Firebase أو Cookie من السورس القديم، وبدون تعديل ربط Meta أو TikTok أو Zoho.

## إعدادات القناة الافتراضية

من صفحة **الإعدادات ← إعدادات التسويق ← ربط المنصات ← YouTube ← إعدادات النشر** يمكن حفظ:

- حالة الظهور الافتراضية: عام، غير مدرج، خاص.
- تصنيف الفيديو.
- اللغة الافتراضية.
- قائمة التشغيل الافتراضية من القناة المربوطة.
- ترخيص YouTube أو Creative Commons.
- تحديد المحتوى المخصص للأطفال.
- إشعار المشتركين.
- السماح بالتضمين.
- إظهار الإحصاءات العامة.
- كلمات مفتاحية افتراضية.
- قالب وصف ثابت.

تُحفظ الإعدادات في PostgreSQL داخل `marketing.platform_publish_settings`.

## إعدادات كل تاسك

عند اختيار YouTube داخل **تجهيز النشر** تظهر إعدادات الفيديو الخاصة بالتاسك:

- العنوان والوصف والكلمات المفتاحية.
- حالة الظهور والتصنيف واللغة.
- قائمة التشغيل والترخيص.
- إعداد الأطفال والإشعارات والتضمين والإحصاءات.

تُحفظ القيم الخاصة بالتاسك داخل `marketing.publish_schedule.publish_options` ولا تغيّر الإعدادات الافتراضية للقناة.

## أنواع نشر YouTube

تم فصل نوع المحتوى عن حالة الظهور:

- فيديو.
- Shorts.

أما القيم القديمة «عام / غير مدرج / خاص» فتم إيقافها كأنواع نشر، وأصبحت إعداد ظهور في مكانها الصحيح، مع الاحتفاظ بسجلات النشر القديمة دون حذف.

## ملاحظات تشغيل

- التصنيفات وقوائم التشغيل تُقرأ من القناة المربوطة باستخدام YouTube Data API.
- يتم تجديد Access Token تلقائيًا عند الحاجة باستخدام Refresh Token المخزن مشفرًا.
- هذا الإصدار يضيف **إعدادات YouTube وتجهيز بيانات الفيديو فقط**. رفع الفيديو فعليًا إلى YouTube لم تتم إضافته ضمن هذا الطلب.
