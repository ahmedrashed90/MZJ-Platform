# دعم الدفعة المقدمة وصفحة متابعة طلبات البيع — 2026-08-05

## نطاق التنفيذ

تم التنفيذ مباشرة على السورس المعتمد الحالي دون نقل ملفات من نسخة سابقة ودون تغيير منطق الإلغاء أو منطق CRM أو العمليات القائم.

## Webhooks الخاصة بطلب البيع

### 1. عند اعتماد طلب البيع

- DocType: `Sales Order`
- Doc Event: `on_submit`
- Event داخل JSON: `sales_order.submitted`
- Request URL:
  `https://mzj-platform.vercel.app/api/integrations/erpnext/sales-order`

الحدث ينشئ أو يحدّث طلب التراكينج الطبيعي، ويحفظ:

- الإجمالي شامل الضريبة `grand_total`
- الدفعة المقدمة `advance_paid`
- بيانات العميل والمندوب والسيارات كما هي في الربط المعتمد

### 2. عند تعديل طلب معتمد

- DocType: `Sales Order`
- Doc Event: `on_update_after_submit`
- Event داخل JSON: `sales_order.updated_after_submit`
- نفس Request URL السابق

هذا الحدث يبحث عن طلب البيع الموجود برقم الطلب/هوية المصدر، ثم يحدّث في نفس السجل فقط:

- الإجمالي شامل الضريبة
- الدفعة المقدمة
- المتبقي المحسوب

لا ينشئ طلب تتبع جديدًا، ولا يعيد إنشاء العميل، ولا يعيد تنفيذ ربط العمليات، ولا ينشئ موافقات جديدة.

## ظهور القيم في التراكينج

تمت إضافة عرض القيم التالية في تفاصيل طلب التراكينج، نافذة التراكينج في الداش بورد، وصفحة التتبع العامة:

- الإجمالي شامل الضريبة
- الدفعة المقدمة
- المتبقي = أكبر قيمة بين صفر و(الإجمالي شامل الضريبة - الدفعة المقدمة)

## صفحة العمليات الجديدة

اسم الصفحة: **متابعة طلبات البيع**

المسار: `/operations/sales-orders`

الصفحة للعرض والمتابعة فقط، وتعرض صفًا مستقلًا لكل سيارة داخل طلب البيع، وتشمل:

1. رقم الطلب
2. اسم العميل
3. رقم الهيكل
4. الإجمالي شامل الضريبة
5. الدفعة المقدمة
6. المتبقي
7. استيفاء المبالغ المتبقية (خاص بالعميل) — المرحلة رقم 6
8. الموافقة المالية — من دورة موافقات السيارة المرتبطة برقم الهيكل
9. الموافقة الإدارية — من دورة موافقات السيارة المرتبطة برقم الهيكل
10. إتمام عملية التسليم بنجاح — المرحلة رقم 10

تظهر جميع طلبات البيع الجديدة، سواء كانت الدفعة المقدمة أكبر من صفر أو تساوي صفرًا.

## الصلاحيات

### العمليات

- الصفحة: `operations.sales_orders_followup.view`
- تظهر داخل: الإعدادات → المستخدمون والصلاحيات → إعدادات وصلاحيات العمليات → متابعة طلبات البيع

### التسويق — تفاعل النشر

تم فصل صفحة تفاعل النشر عن صلاحية تجهيز النشر، وإضافتها داخل إعدادات وصلاحيات التسويق بالصلاحيات التالية:

- `marketing.engagement.view`
- `marketing.engagement.subscribe`
- `marketing.engagement.status.view`
- `marketing.engagement.webhook.view`
- `marketing.engagement.refresh`
