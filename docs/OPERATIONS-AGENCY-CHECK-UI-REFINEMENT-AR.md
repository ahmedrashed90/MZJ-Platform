## التعديلات

- إعادة تنظيم منطقة البحث وبيانات الحركة لتعمل باحترافية على التابلت.
- البحث يظهر بعرض كامل في مقاسات التابلت، والمكان الجديد والحالة الجديدة داخل بلوك واحد مترابط.
- في الهاتف يتحول بلوك المكان والحالة إلى عمود واحد بدون خروج أي حقل خارج العرض.
- جميع عناصر تشييك الوكالة تبدأ افتراضيًا على «صح».
- العنصر غير الموجود فقط يتم تغييره يدويًا إلى «غلط».
- عند التنفيذ تُرسل جميع عناصر التشييك بالقيم الافتراضية `ok` حتى لو لم يضغط المستخدم على كل عنصر.
- الحفاظ على قيم الحفظ `ok` و`missing` وعلى نفس API وقاعدة البيانات ومنطق تنفيذ الحركة.
- لم يتم تعديل أي صفحة أو نظام آخر.
