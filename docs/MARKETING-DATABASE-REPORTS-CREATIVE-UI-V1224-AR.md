# تحسين قاعدة بيانات التسويق وتقارير الكرييتيف — v1.22.4

## نطاق التنفيذ

تم تنفيذ التعديل من المصدر المعتمد مباشرة داخل قاعدة بيانات التسويق، من دون تغيير منطق إنشاء الحملة أو الأجندة أو تدفق اعتماد Task Template والتاسكات التنفيذية.

## واجهة إضافة وتعديل الكرييتيف

- إعادة بناء نافذة إضافة وتعديل الكرييتيف بترويسة مختصرة ومؤشرات واضحة.
- تنظيم خطوات الكرييتيف والميزانية وجدول النشر والمراجعة.
- توحيد شكل الحقول والأزرار وحالات الفراغ.
- نقل أزرار الإلغاء والسابق والتالي والحفظ إلى شريط ثابت ومنظم أسفل النافذة.
- الحفاظ على قواعد المراجعة وإعادة الاعتماد كما هي.

## عرض كرييتيفات الحملة والأجندة

- استبدال الكروت بجدول مضغوط مناسب للأعداد الكبيرة.
- إظهار الكود والنوع والقسم والعدد وعدد Task Templates والتاسكات التنفيذية ومواعيد النشر.
- إظهار إجمالي ميزانية الكرييتيف داخل الحملات فقط.

## تصدير PDF

تم إنشاء تقرير طباعة مستقل A4 أفقي بدل طباعة واجهة المنصة، ويشمل:

- بيانات الحملة أو الأجندة.
- جميع الكرييتيفات.
- جميع Task Templates والتاسكات التنفيذية.
- جدول النشر.
- ميزانية الحملة عند وجودها.
- ملخص نتائج النشر والتفاعل.
- تفاصيل المنشورات ومؤشرات التفاعل والعملاء والمبيعات.

## تصدير Excel

- استبدال ملف HTML المسمى XLS بملف XLSX حقيقي.
- إضافة تنسيق RTL وعناوين وهوية بصرية وحدود وصفوف متبادلة.
- تثبيت رأس الجدول وإضافة الفلترة وضبط الطباعة أفقيًا.
- حماية النصوص من التنفيذ كمعادلات داخل Excel.
- تحسين تقرير جدول النشر وتقرير مراجعة التاسكات.
