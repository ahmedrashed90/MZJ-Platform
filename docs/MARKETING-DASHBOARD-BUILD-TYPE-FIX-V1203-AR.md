# إصلاح Build داش بورد التسويق — v1.20.3

## المشكلة

فشل `pnpm run build` في ملف:

`src/marketing/pages/MarketingDashboardPage.tsx`

بالخطأ `TS2345: Argument of type 'any' is not assignable to parameter of type 'never'` في تجميع تاسكات الأقسام داخل كارتَي `TASK - المطلوب` و`جاهزية المطلوب`.

## السبب

القيمة الافتراضية `tasks: []` تم استنتاجها كـ `never[]` داخل تعبير الدمج مع نتيجة `Map.get()`.

## الإصلاح

تم تثبيت النوع الصريح لكائن التجميع في الموضعين:

`{ name: string; tasks: any[] }`

ولا يوجد أي تغيير في منطق انتقال التاسك أو الحالات أو الصلاحيات أو تصميم الشاشة.
