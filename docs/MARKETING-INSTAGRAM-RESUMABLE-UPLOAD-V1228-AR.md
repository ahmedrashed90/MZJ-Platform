# إصلاح نشر فيديو Instagram بالرفع المباشر إلى Meta — V1228

## المشكلة
كان مسار نشر Reel وStory الفيديو يرسل رابط ملف Zoho داخل `video_url`. خوادم Instagram تحتاج رابطًا عامًا يمكن تنزيله دون ترويسات مصادقة، بينما تنزيل ملفات Zoho داخل المنصة يعتمد على `Zoho-oauthtoken`. أدى ذلك إلى فشل معالجة الفيديو مثل:

- `Media ID is not available`
- `Media upload has failed with error code 2207076`

## التنفيذ النظيف
تمت إزالة منطق Instagram المتفرق من `server/marketing/index.ts` ونقله إلى خدمة واحدة:

- `server/_instagram-publisher.ts`

المسار الجديد للفيديو:

1. إنشاء Media Container مع `upload_type=resumable`.
2. تنزيل الملف من Zoho داخل الخادم باستخدام التوكن الحالي، أو قراءته من R2.
3. تمرير بايتات الفيديو مباشرة إلى `rupload.facebook.com/ig-api-upload`.
4. متابعة `status_code` حتى `FINISHED`.
5. إيقاف التنفيذ عند `ERROR` أو `EXPIRED` وعرض رسالة المعالجة.
6. تنفيذ `media_publish` بعد الجاهزية فقط.
7. إعادة المحاولة المحدودة فقط إذا أعادت Meta خطأ أن Media ID غير جاهز رغم اكتمال المعالجة.

لا يُرسل رابط Zoho المحمي داخل `video_url` في مسار Reel أو Story الفيديو.

## الصور المتعددة
تم الحفاظ على ترتيب الملفات وتفعيل المطلوب في نفس مسار التنفيذ المشترك بين النشر اليدوي والتلقائي:

- بوست الصور المتعددة ينشر كـ Carousel واحد، بحد Instagram من صورتين إلى 10 صور.
- Story الصور المتعددة تنشر كعدة Stories مستقلة بالترتيب داخل نفس دفعة التنفيذ.
- Facebook Story يدعم كذلك دفعة صور مرتبة من نفس مجموعة الملفات.
- Story الفيديو يظل ملف فيديو واحدًا؛ خلط فيديو وصور أو رفع عدة فيديوهات في نفس النوع مرفوض برسالة واضحة.

## نطاق التعديل
لم يتم تغيير تصميم الواجهة أو CRM أو العمليات أو التتبع أو إعدادات المنصات أو منطق YouTube وFacebook Reel.

## الاختبارات
- اختبار مسار Reel بالرفع الثنائي المباشر: نجح.
- اختبار Story بصورتين مع الحفاظ على الترتيب: نجح.
- فحص Instagram الجديد: `10/10`.
- جميع فحوص المشروع البرمجية القائمة: `68/68`.
- فحص TypeScript معزول لخدمة Instagram الجديدة: نجح.
- تعذر تشغيل بناء المشروع الكامل داخل بيئة التسليم لعدم وجود حزم `node_modules` وعدم توفر اتصال بسجل npm؛ الأخطاء الناتجة كانت فقدان React وتعريفات Node وليست أخطاء من التعديل.

## متغيرات اختيارية
القيم الافتراضية مناسبة دون إضافة متغيرات جديدة. ويمكن ضبط الآتي عند الحاجة:

- `INSTAGRAM_MEDIA_READY_TIMEOUT_MS`
- `INSTAGRAM_MEDIA_READY_POLL_MS`

يتم تقييد القيم داخليًا بما يتوافق مع مدة Vercel الحالية.
