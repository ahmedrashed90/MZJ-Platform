# تطبيق مناديب CRM — إصدار تجريبي V2

تم تنفيذ وضع تطبيق مخصص على السورس الأساسي مباشرة دون تغيير منطق CRM أو API أو قاعدة البيانات.

## النطاق داخل التطبيق المثبت
- داش بورد CRM.
- إضافة العملاء.

## سلوك نسخة الويب
نسخة الويب العادية تظل منصة موحدة كاملة. وضع التطبيق يتفعل فقط عند فتح الرابط بمعامل `crmSalesApp=1` أو عند التشغيل كتطبيق مثبت Standalone.

## حماية عمليات البيانات
- لا يوجد Cache لطلبات API.
- لا يوجد Background Sync.
- لا يعاد إرسال POST أو PUT أو PATCH أو DELETE بواسطة Service Worker.
- الصلاحيات الحالية هي التي تتحكم في فتح الداش بورد وإضافة العملاء.
