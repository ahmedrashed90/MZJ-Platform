# إتمام التسليم وأرشفة السيارة

عند إكمال مرحلة التراكينج الأخيرة «إتمام عملية التسليم بنجاح»، يستدعي النظام مسار الأرشفة التلقائية الأصلي.

بعد تحقق الشروط الموجودة مسبقًا:

1. اكتمال الموافقة المالية والإدارية.
2. عدم وجود طلب نقل جاري أو غير مكتمل.
3. اكتمال جميع مراحل التراكينج النشطة للسيارة.

يتم داخل معاملة واحدة:

- تحديث `operations.vehicles.status_code` إلى `delivered` («مباع تم التسليم»).
- تعيين بيانات الأرشفة.
- ضبط `is_inventory_active=false`.
- تسجيل حدث الأرشفة الحالي.

لا توجد تغييرات على الواجهة أو ترتيب المراحل أو الصلاحيات أو قاعدة البيانات.
