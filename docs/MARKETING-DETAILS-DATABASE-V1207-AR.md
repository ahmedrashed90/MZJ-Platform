# تحسين تفاصيل التسويق وعرض قاعدة البيانات — v1.20.7

## المصدر

تم التنفيذ مباشرة على سورس v1.20.6 المعتمد، مع تعديل المكونات والتنسيقات الأصلية فقط.

## التعديلات

- توسيع صفحة تفاصيل Task Template لتستخدم عرض الشاشة بالكامل وتقليل الهوامش الجانبية.
- زيادة عدد أعمدة ملخص التكليف على الشاشات الواسعة مع استجابة كاملة للشاشات الأصغر.
- توسيع عرض بيانات Task Template المعتمدة مع بقاء السكريبت الأساسي بعرض كامل.
- تحويل شاشة «عرض البيانات» في قاعدة بيانات التسويق إلى شاشة كاملة.
- تنظيم بيانات الحملة والتاسكات وملفات المنتجات والميزانية والنتائج والروابط داخل أقسام واضحة تستغل عرض الشاشة.
- عرض جدول النشر في ثلاثة أعمدة: اليوم، المنصة، نوع النشر.
- دمج اليوم والمنصة بصريًا باستخدام `rowSpan` عند تكرارهما، بنفس فكرة المرجع المرسل.
- الحفاظ على جميع وظائف التحميل والرفع والتصدير والحفظ والأرشفة الحالية بدون تغيير منطقها.

## نطاق التعديل
