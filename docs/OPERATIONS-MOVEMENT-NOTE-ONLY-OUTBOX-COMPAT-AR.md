# تحديث ملاحظة السيارة بدون حركة فعلية

## النطاق
تم تعديل مسار **العمليات > الحركة** فقط بحيث يسمح للإداري بحفظ حقل **حجز - نواقص - تحديد مكان** عندما تكون السيارة موجودة بالفعل في نفس المكان ونفس الحالة.

## السلوك المعتمد
- إذا تغير المكان أو الحالة: يتم تنفيذ الحركة بنفس المنطق السابق.
- إذا لم يتغير المكان أو الحالة ووجدت ملاحظة جديدة: يتم تحديث ملاحظة السيارة وتسجيل حدث `note_update` داخل سجل الحركات، بدون تغيير المكان أو الحالة.
- إذا لم يتغير المكان أو الحالة ولم توجد ملاحظة جديدة: يستمر منع العملية باعتبارها عملية بدون أي تغيير.
- تحديث الملاحظة فقط لا يعيد كتابة تشيك الوكالة الافتراضي ولا يغير الموافقات.

## توافق event_outbox
تم توحيد إدخالات جدول `operations.event_outbox` مع قواعد البيانات القديمة التي تحتوي على العمودين الإلزاميين:
- `aggregate_type`
- `aggregate_id`

تم تطبيق التوافق على أحداث حركة السيارات وطلبات النقل ومسح طلبات التراكينج.
