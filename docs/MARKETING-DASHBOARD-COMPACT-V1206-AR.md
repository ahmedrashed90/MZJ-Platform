# تعديل داش بورد التسويق — v1.20.6

## المصدر

تم التنفيذ مباشرة على سورس v1.20.5 المعتمد. لم يتم إنشاء Patch منفصل، ولم تتم إضافة CSS Overrides في نهاية الملف؛ تم تعديل المكوّن والتعريفات الأصلية نفسها.

## التعديلات

1. تصغير رؤوس بلوكات الأقسام إلى ارتفاع مدمج، وتقليل الحواف والمسافات الداخلية.
2. إزالة الدائرة الكبيرة التي كانت تعرض `عدد المكتمل/الإجمالي` مع النسبة داخلها.
3. عرض ملخص القسم في مستطيل صغير يحتوي على عدد التاسكات ونسبة الاكتمال بشكل منفصل ومقروء.
4. إزالة عداد تاسكات الحملة الدائري وعرضه كوسم مستطيل صغير.
5. عرض نسبة اكتمال الحملة في وسم مستقل داخل رأس الحملة بدل وضع الرقم فوق شريط داكن.
6. تفتيح شريط تقدم الحملة والتاسكات مع إبقائه مؤشرًا بصريًا فقط.
7. الحفاظ على فتح وإغلاق الحملات والأقسام، التحديث اللايف كل ثانية، ألوان المسؤولين، وانتقال التاسك بعد الاستلام.
