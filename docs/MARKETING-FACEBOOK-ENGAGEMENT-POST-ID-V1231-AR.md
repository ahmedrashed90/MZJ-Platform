# تصحيح تحديث تفاعل Facebook — Post ID كامل — V1231

تم تنفيذ التصحيح مباشرة داخل مسار تسجيل المنشور وتحديث التفاعل، دون إضافة API بديل أو مسار ترقيع.

## سبب الخطأ

بعض مسارات نشر Facebook للفيديو وReels ترجع معرف الوسائط/الفيديو فقط. كان هذا المعرف يُحفظ في `provider_post_id` ثم يُستخدم لاحقًا كأنه معرف Post كامل عند الضغط على **تحديث الأرقام الآن**. نتيجة ذلك كانت Meta تعتبر الطلب محاولة للوصول إلى صيغة Status قديمة وترجع الخطأ `(#12) singular statuses API is deprecated for versions v2.4 and higher`.

## التعديل

- توحيد معرف منشور Facebook إلى صيغة Page Post الكاملة `pageId_postId` عند تسجيل أي منشور جديد.
- إصلاح السجلات القديمة تلقائيًا أثناء أول تحديث تفاعل ناجح، بدون SQL يدوي.
- الإبقاء على `provider_media_id` مستقلًا لمعرف الفيديو/الوسائط.
- استخدام معرف Post الكامل فقط لقراءة `reactions` و`comments` و`shares` و`permalink_url`.
- حفظ المعرف المصحح في نفس سجل `marketing.published_posts` بعد نجاح المزامنة.

هذا التصحيح لا يغير مسار النشر نفسه ولا Facebook Reel binary upload ولا تحميل الملفات النهائية من تجهيز النشر.
