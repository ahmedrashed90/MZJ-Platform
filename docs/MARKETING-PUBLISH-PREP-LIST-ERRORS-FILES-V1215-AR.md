# تجهيز النشر: القائمة وسبب الخطأ والملفات النهائية — V1.21.5

تم التنفيذ مباشرة على سورس المنصة الحالي بدون طبقات توافق أو باتشات منفصلة.

## صفحة تجهيز النشر

- تحويل عرض التاسكات من شبكة كروت إلى قائمة رأسية، وكل تاسك يظهر كسطر كامل تحت السابق.
- تاريخ النشر أصبح موعدًا مرجعيًا للجدول فقط، ولا يمنع الضغط على «نشر الآن» في أي وقت.
- إضافة زر «نشر الآن» داخل كل تاسك، مع استمرار دعم تحديد عدة تاسكات والنشر الجماعي.
- إضافة نتيجة مستقلة لكل منصة ونوع نشر بعد التنفيذ.
- عرض نص الخطأ الحقيقي القادم من Backend بدل رسالة عدد الأخطاء فقط.
- حفظ حالة الفشل وسببها في `marketing.publish_schedule.publish_result` وفي `marketing.publish_logs`.
- قراءة آخر نتيجة لكل عنصر نشر، ولذلك يظهر سبب المحاولة السابقة بعد تحديث الصفحة.
- اسم الملف النهائي أو الصور المرتبة أصبح قابلًا للضغط ويفتح الملف من Zoho WorkDrive.

## قاعدة البيانات — عرض ملفات المنتجات

- عرض الملفات النهائية الجاهزة والمرتبطة حاليًا بالتاسكات فقط.
- استبعاد محاولات الرفع الفاشلة أو الملغاة والمجموعات القديمة غير المعتمدة.
- تصميم صف ملفات جديد يعرض الاسم، الكرييتيف، المسؤول، الحجم، الترتيب، وزر «فتح الملف» واضح.

## ما لم يتغير

- إنشاء الحملة والأجندة.
- منطق إنشاء التاسكات.
- شروط ظهور رفع الملف النهائي.
- رفع الملفات إلى Zoho WorkDrive.
- المنصات وأنواع النشر المحفوظة.
