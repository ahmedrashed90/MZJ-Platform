# نظام الإشعارات الداخلي في منصة MZJ

## النطاق

تم بناء نظام إشعارات داخلي مركزي داخل السورس الحالي دون إضافة أي تبويب إلى صفحات CRM أو التسويق أو العمليات أو التراكينج، ودون تغيير منطق أو تصميم الصفحات القائمة.

- داخل كل نظام يعرض الجرس إشعارات النظام المفتوح فقط.
- مدير النظام يرى كل إشعارات المنصة من المسار `/notifications`.
- المستخدم العادي لا يستطيع فتح مركز إشعارات المنصة الكامل.
- القراءة والحذف المنطقي للإشعار مستقلان لكل مستخدم.
- الإشعارات محفوظة في PostgreSQL وليست بيانات مؤقتة أو تجريبية.

## قاعدة البيانات

- `core.notifications`: سجل الإشعارات والأحداث والنظام والمستلم والنطاق والرابط.
- `core.notification_user_state`: حالة القراءة والإخفاء لكل مستخدم ولكل إشعار.
- Migration: `database/migrations/20260727_internal_notifications.sql`.
- يوجد تهيئة آمنة تلقائية للجداول للنسخ القائمة.

## العزل والصلاحيات

1. الإشعار مرتبط بنظام واحد: `crm` أو `marketing` أو `operations` أو `tracking`.
2. المستخدم يرى إشعارات الأنظمة المفعلة له فقط.
3. الإشعار الموجه لمستخدم بعينه يظهر له مباشرة.
4. الإشعارات العامة تخضع لنطاق الفرع والقسم الخاص بكل نظام بصورة مستقلة.
5. مدير النظام يشاهد السجل الكامل من مركز الإشعارات، وعند دخوله إلى نظام محدد يعرض الجرس إشعارات هذا النظام فقط.

## الأحداث المربوطة

### CRM

- دخول عميل جديد يدويًا أو من القنوات.
- دخول عميل جديد من NEXT ERP.
- رسالة واردة من عميل.
- تحديث حالة العميل.
- تحويل العميل إلى قسم أو فرع آخر.

### التسويق

- إنشاء حملة.
- إنشاء أجندة.
- إسناد تكليف للمستخدم المختار.
- استلام التكليف.
- رفع Task Template.
- المراجعة والاعتماد.
- تنفيذ إجراء من إجراءات التكليف.
- رفع الملف النهائي والنشر والأرشفة.
- نسب تقدم 25% و50% و75% و100%.

### العمليات

- إضافة أو تحديث أو أرشفة سيارة.
- إنشاء طلب حركة أو نقل.
- تغير مرحلة الطلب.
- تحديث الموافقات.
- تنفيذ حركة سيارات أو استيرادها.

### التراكينج

- إنشاء طلب تتبع من المسار الموحد لـ NEXT ERP أو Google Sheets.
- إنهاء مرحلة.
- التراجع عن مرحلة.
- أرشفة أو استعادة الطلب.

## الواجهة

- مكون الجرس: `src/notifications/NotificationBell.tsx`.
- مركز مدير النظام: `src/notifications/NotificationsCenterPage.tsx`.
- لا توجد تعديلات على تبويبات Layout الخاصة بالأنظمة الأربعة.
- تحديث تلقائي أثناء الاستخدام وعند عودة التركيز إلى الصفحة.

## موضع الجرس والتنبيه المباشر

- الجرس موجود داخل منطقة حساب المستخدم أسفل القائمة الجانبية، وليس داخل شريط تبويبات أي نظام.
- يظهر بادج أحمر بعدد الإشعارات غير المقروءة.
- يتم فحص الإشعارات الجديدة كل 5 ثوانٍ وأيضًا عند عودة التركيز إلى الصفحة.
- عند وصول إشعار جديد يتم تشغيل صوت تنبيه وإظهار كارت صغير داخل الصفحة.
- مدة الكارت الافتراضية 5 ثوانٍ، ويغلق تلقائيًا أو يدويًا.
- الضغط على الكارت يعلّم الإشعار كمقروء ويفتح الرابط المرتبط به.

## إعدادات الإشعارات

- تظهر داخل صفحة الإعدادات في قسم مستقل باسم `إعدادات الإشعارات`.
- الإعدادات محفوظة لكل مستخدم داخل `core.notification_preferences`.
- يمكن التحكم في صوت الإشعار، والكارت المؤقت، ومدة ظهوره، والتنبيه المباشر لكل نظام.
- تعطيل تنبيه نظام يمنع الصوت والكارت لهذا النظام فقط؛ يظل الإشعار محفوظًا في الجرس ومركز الإشعارات.
