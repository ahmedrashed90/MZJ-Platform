# تعديل إنشاء حملات وأجندات التسويق — منتجات فريدة ومنصات متعددة

التطبيق: `src/marketing/workflow/CreatePage.tsx` و `src/marketing/workflow/planComposer.ts`

## القواعد المعتمدة

- المنتج/المطلوب المختار في يوم لا يظهر في اختيارات الأيام الأخرى **داخل نفس الحملة أو الأجندة الحالية**. عند إزالة اليوم أو تغيير اختياره يعود المنتج للاختيار؛ لا يُحذف من قاعدة المنتجات ولا يُمنع استخدامه في خطط أخرى.
- يتاح اختيار منصة واحدة أو أكثر لنفس المنتج في اليوم نفسه، وتظهر المنصات من إعدادات التسويق النشطة، وبشرط وجود نوع نشر متوافق مع نوع المنتج (صورة أو فيديو).
- لكل منصة محددة قائمة أنواع نشر مستقلة ومصفاة حسب المنصة ووسيط المنتج. عندما يكون النوع المتوافق واحدًا فقط، يُختار تلقائيًا، وإلا يختاره المستخدم.
- في إنشاء الحملة، الميزانية مستقلة لكل منصة؛ إجمالي اليوم هو مجموع المبالغ. لا يتم نسخ ميزانية واحدة إلى جميع المنصات دون علم المستخدم.
- في إنشاء الأجندة، لا توجد ميزانية، ويُحفظ صفر حسب المنطق السابق.
- المعاينة تعرض صفًا لكل منصة، مع المنتج، الفكرة، التاريخ، نوع النشر، وميزانيتها إن كانت حملة.

## الحفظ والتوافق

- أُضيفت بنية إدخال مجمعة `entries[].platforms[]` على مسار `work_create_plan` الأصلي. كل منصة تتحول إلى سطر نشر عادي ومستقل في `marketing.work_plan_items`، دون تغيير أي جدول أو فصل الربط بالمنتجات والمراجعات والنشر.
- التحقق من عدم تكرار المنتج داخل الخطة، وصلاحية المنصة، ونوع النشر، والميزانيات يتم على الواجهة والسيرفر.
- الحمولة القديمة المفردة (`entries[].postTypeId`) ما زالت مقبولة لاستمرار توافق الواجهات القديمة، دون تعديل سجلات الحملات والأجندات الموجودة.
- لا توجد قاعدة بيانات أو متغير Vercel جديد مطلوب لهذه الإضافة.

## الاختبارات

- `node scripts/test-marketing-plan-multiplatform-20261017.mjs` — تغطية المنتج الفريد والصورة والفيديو والتخزين على منصتين والصلاحيات والمدخلات غير السليمة والتوافق مع الحمولة القديمة.
- `node scripts/test-marketing-plan-ui-20261017.mjs` — تشغيل مكوّن إنشاء الحملة والأجندة فعليًا باستخدام React JSX mock محلي، مع محاكاة تحديد المنتج والمنصات والتاريخ والميزانية ثم حفظ الطلب.
- جميع اختبارات المشروع التي تسبق `tsc -b` اجتازت الفحص. لم يكتمل فحص الـBuild محليًا لأن مكتبات React والأنواع التابعة لها غير مثبّتة في بيئة العمل؛ يُرجى تشغيل `pnpm install --frozen-lockfile && pnpm run build` على بيئة Vercel/Preview قبل الترقية للإنتاج.
