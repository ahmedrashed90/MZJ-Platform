# تعديل الحملة والأجندة — 01/11/2026

## نطاق التغيير

- في إنشاء الحملة، ميزانية مستقلة لكل **نوع نشر مختار في منصة محددة**، بدل ميزانية واحدة للمنصة. كل (مطلوب، منصة، نوع نشر، يوم) ينشئ بند نشر محفوظ بميزانيته الخاصة. مثال: بوست إنستجرام 100 ر.س، ستوري إنستجرام 50 ر.س، المجموع 150 ر.س.
- منع الحفظ عند عدم إدخال ميزانية أي نوع نشر مختار. يسمح بالمبلغ صفر للمنشورات غير الممولة، وتظهر ميزانية كل صف داخل تجهيز النشر والمراجعة والتقرير. لا يتم تغيير موازنات الحملات السابقة.
- حذف زر «تفاصيل الجدول» من كروت النشر عند الاعتماد مع الإبقاء على «مراجعة واعتماد» قبل الاعتماد. العلامة الخضراء «حملة معتمدة / أجندة معتمدة» قابلة للضغط لفتح التفاصيل بعد الاعتماد.
- إزالة رسالة عدم دعم النشر التلقائي من الكارت فقط؛ **ضوابط النشر التلقائي الفعلية لا تزال محمية بصلاحيات المنصة ووجود المزوّد المدعوم**.
- إظهار الاسم المسجل لمنشئ الحملة / الأجندة في نافذة التفاصيل، من `core.users.full_name` عبر `marketing.work_plans.created_by`.
- أول حفظ ناجح لرابط منشور يدوي يثبّت الرابط وتاريخ الحفظ بتوقيت السعودية. لا يسمح النظام بتغييره أو استبداله أو حذفه لاحقًا، حتى بطلب API مباشر. التحقق داخل معاملة قاعدة البيانات مع قفل السجل.
- مسار القاعدة والعمليات السابق لم يُغيّر. لا توجد حاجة إلى ترحيل قاعدة بيانات جديد.

## الحفاظ على التوافق

- يحتفظ السيرفر بدعم صيغة البيانات القديمة ذات الميزانية الواحدة للمنصة لحملات سابقة أو عملاء قدامى، دون إعادة توزيع ميزانيات منشورة مسبقًا.
- إنشاء الأجندة لا يطلب ميزانيات.
- تظهر ميزانيات الصفوف في مراجعة الحملة والتجهيز والتقرير كما هي محفوظة.
- تعديلات الحضور والداش بورد الرئيسية الموجودة في السورس المرجعي محفوظة.
