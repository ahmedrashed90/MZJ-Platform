# تعديلات الداش بورد وسجل الحركات

- أصبح كارت الموافقات المالية والإدارية قابلًا للفتح من أي مساحة غير تفاعلية داخل الكارت، مع بقاء أزرار الحالات الثلاث تفتح الفلتر المحدد.
- توحيد معادلة الإجمالي الفعلي في ملخص الداش بورد وتفاصيل العرض: جميع السيارات النشطة غير المؤرشفة مع استبعاد حالتي مباع تحت التسليم ومباع تم التسليم.
- إعادة بناء طباعة سجل الحركات على صفحات A3 أفقية متعددة بثماني حركات لكل صفحة، مع رؤوس واضحة، ترقيم صفحات، وعدم تقسيم الصف، وإظهار المراجع التقنية الكاملة أسفل كل صفحة بدل ضغطها داخل أعمدة الجدول.
- لم يتم تغيير دورة الموافقات أو منطق المخزون أو الصلاحيات خارج البنود المطلوبة.
