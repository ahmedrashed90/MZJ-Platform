# تصحيح اشتراك تعليقات Meta وعرض الخطأ التفصيلي — V1219

تم تعديل الفلو الأصلي مباشرة داخل صفحة تفاعل النشر وخدمة Meta دون إضافة مسار بديل أو طبقة ترقيع.

## التعديل

- تنفيذ اشتراك Facebook وInstagram كل منصة بشكل مستقل.
- التحقق بعد الاشتراك عبر قراءة `subscribed_apps` والتأكد من وجود `feed` أو `comments`.
- اختيار Graph host وفق نوع ربط Instagram: Facebook Login أو Instagram Login.
- عدم تحويل الفشل الجزئي إلى خطأ HTTP يخفي `results`.
- عرض رسالة Meta الأصلية مع Code وSubcode وTrace ID والصلاحيات الناقصة.
- حفظ آخر نتيجة اشتراك لكل منصة وإظهارها بعد إعادة تحميل الصفحة.

لا يوجد SQL يدوي ولا تغيير في منطق النشر أو تحويل التعليقات إلى CRM.
