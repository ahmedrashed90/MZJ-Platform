# MZJ Owners Community - Repeat Existing Customer Rewards

تم تنفيذ التعديل على المصدر الكامل مع إبقاء جميع الأنظمة الأخرى دون تغيير.

- إزالة الحظر الدائم المرتبط برقم جوال العميل من `owners.referral_purchase_benefits`.
- الإبقاء على `website_order_id` فريدًا لضمان Idempotency ومنع احتساب المكافأة مرتين لنفس الطلب.
- أي عميل لديه استفادة سابقة يصنف في الطلب التالي كعميل قديم (`existing`) حتى لو لم تكن مزامنة البيع التاريخية قد اكتملت بعد.
- العميل القديم يرى فقط المكافآت المفعلة له.
- العميل الجديد يرى مكافآت العميل الجديد ومكافآت العميل القديم وفق إعدادات الكتالوج.
- فلو الإحالة للعميل الجديد لم يتغير، ولا يتم إنشاء Referral جديد للعميل القديم.
- لم تتم إضافة ملف Migration منفصل؛ `ensureOwnersSchema()` يزيل قيد الهاتف القديم بطريقة Idempotent عند تشغيل النسخة.
