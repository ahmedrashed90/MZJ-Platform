# توحيد بيانات داش بورد العمليات مع صفحات العمليات

تم تنفيذ التعديل من مصدر البيانات الأساسي للعمليات دون إنشاء مصدر موازٍ أو منطق حساب منفصل داخل الداش بورد.

## النطاق المنفذ

- توحيد كارت **طلبات النقل والتصوير** مع جدول `operations.transfer_requests` المستخدم في تبويب **الطلبات → متابعة الطلبات**.
- احتساب طلبات النقل والتصوير حسب `request_kind` من نفس الجدول.
- احتساب مراحل الطلب الحية: تم استلام الطلب، تم استلام السيارة، تم إرسال السيارة، تم الانتهاء.
- استبعاد طلب مكتمل من الكارت ومن قائمة الطلبات المكتملة بعد أرشفة جميع سياراته، ولذلك تصبح قيمة **تم الانتهاء** صفرًا عند عدم وجود طلبات مكتملة نشطة أخرى.
- إتاحة حذف الطلب الملغي بصلاحية حذف الطلب، مع استمرار منع حذف الطلب غير الملغي بعد بدء التنفيذ.
- توحيد كارت **الموافقة المالية والإدارية** مع نفس نطاق وفلاتر تبويب الموافقات.
- إصلاح قائمة نتائج **إدارة السيارات → البحث للتعديل** وربطها داخل بلوك البحث بدل تمددها فوق الصفحة.
- إصلاح تعارض CSS العام الذي كان يجعل نص أزرار الحذف الحمراء غير ظاهر.

## قاعدة البيانات

لا يحتاج هذا التعديل إلى ملف SQL أو Migration جديدة.
