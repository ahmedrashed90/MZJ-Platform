# ربط نطاق «المسند إليه» بطلبات التراكينج

تم تعديل نطاق بيانات التراكينج بحيث يعمل خيار **المسند إليه** على مندوب الطلب الفعلي، وليس على فرع الطلب.

## المنطق المعتمد

- يضاف إلى طلب التراكينج حقل داخلي `assigned_to` مرتبط بيوزر المنصة.
- عند استقبال أو تحديث طلب NEXT ERP، تتم مزامنة `assigned_to` مع اليوزر المرتبط بحقل `NEXT ERP User ID`.
- الطلبات الموجودة سابقًا تُرحّل تلقائيًا من جدول ربط طلبات NEXT ERP عند تشغيل مخطط التراكينج.
- عند اختيار نطاق **المسند إليه**، لا يظهر الطلب لمجرد أنه تابع لنفس الفرع؛ يجب أن يكون `assigned_to` مساويًا لليوزر الحالي.
- نفس النطاق مطبق على قائمة الطلبات، تفاصيل الطلب، أرقام الداش بورد، تنفيذ المراحل، الرسائل، الأرشفة والحذف.
- نطاقات كل البيانات والفروع ومراحل العمل تظل تعمل بصورة مستقلة دون تغيير صلاحياتها.
