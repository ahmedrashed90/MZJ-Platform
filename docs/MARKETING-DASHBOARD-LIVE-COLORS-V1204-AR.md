# داش بورد التسويق — الألوان والتحديث اللايف v1.20.4

## المصدر

تم التنفيذ مباشرة على سورس `v1.20.3` الكامل، داخل المسارات الأصلية، بدون ملف Patch منفصل أو طبقة توافق جانبية.

## التعديلات

- إخفاء سطر «كاتب المحتوى» عندما يكون نفس حساب «المسؤول»؛ يظهر المسؤول مرة واحدة فقط.
- قراءة لون المسؤول وكاتب المحتوى من جدول `marketing.user_colors`، وهو نفس مصدر «إعدادات سيستم التسويق ← تعيين لون لكل مسؤول».
- إزالة اللون الأزرق الثابت الذي كان مكتوبًا داخل CSS لكاتب المحتوى.
- تثبيت اتجاه نسبة الاكتمال `LTR` واستخدام أرقام واضحة، مع زيادة وضوح بادج النسبة فقط دون إعادة تصميم الكروت.
- إضافة نبضة بيانات خفيفة `dashboard_version` كل ثانية أثناء ظهور الصفحة، وتحميل بيانات الداش بورد بصمت عند وجود تغيير.
- التحديث اللايف يشمل تغييرات التاسكات، إجراءات التكليف، مراجعات Task Template، الحملات، الأجندات، وألوان المسؤولين.
- الحفاظ على حالة فتح وإغلاق الحملات والأقسام أثناء التحديث التلقائي.

## النطاق غير المتغير

- لا تغيير في فلو «تم الاستلام».
- لا تغيير في حالات التاسكات أو نسب إجراءات التكليف.
- لا تغيير في الصلاحيات أو الأدوار أو `role_id`.
- لا Migration ولا SQL يدوي.
- لا تعديل في تصميم أو تنسيق الصفحات الأخرى.
