# إصلاح تنزيل صور Zoho للنشر على Facebook

## السبب
ربط Zoho كان يطلب صلاحية قراءة بيانات ملفات WorkDrive ورفع الملفات، لكنه لم يطلب صلاحية تنزيل المحتوى الثنائي `ZohoFiles.files.READ`. لذلك لم يكن مسار النشر يضمن الحصول على بايتات الصورة الفعلية قبل إرسالها إلى Facebook.

## التعديل
- إضافة `ZohoFiles.files.READ` إلى صلاحيات OAuth الخاصة بـZoho.
- استخدام `download_url` العائد من بيانات الملف بدل الاعتماد على عنوان ثابت فقط.
- متابعة التحويلات أثناء التنزيل.
- فحص بصمة PNG/JPEG/GIF/WebP قبل إرسال الملف إلى Facebook.
- إظهار خطأ واضح من Zoho قبل استدعاء Facebook إذا لم يكن المحتوى صورة فعلية.

## خطوة تشغيل لازمة
بعد نشر النسخة يجب فصل Zoho WorkDrive وإعادة ربطه مرة واحدة حتى يحصل Refresh Token على الصلاحية الجديدة. لا يلزم إعادة ربط Facebook.
