# إتاحة قسم الجملة في تعديل عميل CRM — الإصدار 1.19.15

## المصدر

تم التنفيذ مباشرة على النسخة المرفوعة `MZJ-Platform-v1.19.14-CUSTOMER-REGISTRY-OPERATIONS-BUDGET-CLEAN(1).zip`، داخل مكوّن تعديل العميل الأصلي، دون إنشاء صفحة بديلة أو Endpoint إضافي أو ملف Patch تشغيلي.

## التعديل الوظيفي

داخل CRM ← قاعدة البيانات ← تعديل بيانات العميل:

- قائمة «القسم» تعرض الآن «قسم الجملة» إلى جانب مبيعات الكاش ومبيعات التمويل وخدمة العملاء.
- يتم التعرف على كودي القسم المستخدمين في البيانات الحالية: `wholesale` و`wholesale_sales`.
- عند وجود تكليفات مركزية لموظفي الجملة، تستخدم الواجهة كود القسم الفعلي الموجود في تكليفات مستخدمي CRM.
- قسم الجملة يظل ضمن مسار مبيعات الكاش من ناحية الحالات وطريقة الدفع، مع الاحتفاظ بكود القسم المستقل في `department_code`.
- قسم الجملة يظل بلا فرع حسب المنطق المعتمد؛ لذلك يُمسح الفرع عند اختياره، ويظهر حقل الفرع معطلاً برسالة «قسم الجملة بدون فرع».
- قائمة المسؤولين تُقيد تلقائياً بالمستخدمين المرتبطين بقسم الجملة.
- الحفظ يرسل `serviceKey` و`departmentCode` إلى مسار PATCH الحالي ويحدث نفس سجل العميل، دون إنشاء عميل جديد.

## إصلاح منع النشر

كانت النسخة المرفوعة تحتوي أخطاء TypeScript `TS7006` داخل عرض ميزانية قاعدة بيانات التسويق. تم إصلاحها بتعريف نموذج TypeScript صريح لبند الميزانية والمنصة، وإضافة الأنواع إلى callbacks التي ظهرت في سجل Vercel، دون تغيير حسبة الميزانية أو أي منطق تسويقي.
