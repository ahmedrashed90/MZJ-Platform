# سجل العملاء وفلتر طلبات البيع وإدارة ميزانية الحملات — الإصدار 1.19.14

## نطاق التنفيذ

بُني الإصدار مباشرة من المصدر المعتمد 1.19.13، دون إضافة Migration جديدة أو خدمة موازية أو ملفات Patch جانبية.

### CRM — سجل العملاء

- تغيير اسم صفحة «سجل عملاء التمويل» إلى «سجل العملاء» في التنقل وكتالوج الصلاحيات المركزي.
- تقسيم الصفحة داخليًا إلى «عملاء الكاش» و«عملاء التمويل» و«فروقات حالات العملاء».
- توحيد تصنيف العميل من الحقول المعتمدة `service_key` ثم القسم ثم نوع الدفع.
- قصر مقارنة فروقات الحالات على عملاء التمويل فقط.

### العمليات — متابعة طلبات البيع

- حذف تبويب الطلبات المكتملة من الواجهة، واستمرار الصفحة في عرض الطلبات غير المكتملة فقط.
- حذف بلوك عنوان ووصف الصفحة المطلوبين.
- توحيد مصدر الفرع الفعلي للطلب من ربط ERPNext والفرع المركزي ومكان السيارة وطلب التتبع.
- استخدام نفس الفرع الفعلي في صلاحيات البيانات وفلتر الفرع، مع بناء قائمة الفروع من البيانات المركزية النشطة.

### التسويق — ميزانية الحملة

- إضافة زر «إنشاء الميزانية / تعديل الميزانية» داخل عرض بيانات الحملة كاملة.
- إضافة مدير كامل لبنود الميزانية يدعم Funnel والكرييتيفات والمنصات والأهداف.
- دعم إنشاء Funnel جديد من مدير الميزانية الحالي.
- حفظ الميزانية في الجداول المركزية الحالية `marketing.budget_items` و`marketing.budget_item_creatives` داخل Transaction واحدة.
- إجمالي كل بند هو مجموع مبالغ المنصات مرة واحدة فقط؛ لا يتضاعف بعدد الكرييتيفات أو المنصات المرتبطة.
- إعادة تصميم عرض الميزانية بشكل احترافي مع ملخصات وبطاقات وإجماليات Funnel والإجمالي الكامل.

## التوافق

- لا توجد Migration جديدة لهذا الإصدار.
- لم تتغير مسارات الصفحات أو أسماء الصلاحيات التقنية الحالية.
- لم يتغير منطق إنشاء الحملات أو الأجندات أو تاسكات التسويق خارج إدارة الميزانية المطلوبة.
