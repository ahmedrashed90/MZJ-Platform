# إعدادات أبعاد المنصات والنشر اليدوي النظيف — V1227

## النطاق

هذا التحديث محصور في إعدادات أنواع النشر، وتجهيز النشر، وإدخال محتوى نشر يدوي جديد. لم يغيّر تصميم الصفحات أو منطق CRM أو العمليات أو التتبع.

## الأبعاد المعتمدة

- Instagram: بوست صور `1080×1080`، ريل `1080×1920`، ستوري `1080×1920`.
- TikTok: ريل/فيديو `1080×1920`، ستوري `1080×1920`.
- Snapchat: Spotlight `1080×1920`، Story `1080×1920`.
- Facebook: بوست صور `1080×1080`، ريل `1080×1920`، ستوري `1080×1920`.
- LinkedIn: بوست `1080×1080`، فيديو `1080×1920`.
- YouTube: Shorts `1080×1920`، فيديو `1920×1080`.

تم تعطيل الأنواع القديمة المتعارضة، ومنها YouTube «ريل/Short» وLinkedIn «ريل»، بدل إبقائها ضمن الاختيارات الفعالة.

## تجهيز النشر

- الإعدادات ترجع نوع التنفيذ المنظم مع العرض والارتفاع.
- المتصفح يقرأ أبعاد الصور والفيديو ومدة الفيديو قبل الرفع.
- تحفظ الأبعاد والمدة مع الملف النهائي.
- عند حفظ تجهيز النشر تتم مقارنة الملف بكل نوع نشر مختار.
- تحفظ الأبعاد المطلوبة داخل سجل النشر نفسه حتى لا يتغير المقصود إذا عدّل أحد إعدادات المنصة لاحقًا.
- يعاد التحقق مرة أخرى قبل النشر الفعلي.
- YouTube Shorts يتطلب `1080×1920` ومدة لا تتجاوز ثلاث دقائق.

## النشر اليدوي

النشر اليدوي لم يعد يعرض حملات أو أجندات أو كرييتيفات موجودة. الفلو الجديد:

1. اختيار إنشاء حملة جديدة أو أجندة جديدة.
2. كتابة اسم السجل الجديد.
3. كتابة اسم كرييتيف جديد.
4. رفع صور أو فيديو جديد من الجهاز.
5. اختيار المنصات وأنواع النشر والموعد والكابشن والهاشتاج.
6. التحقق من الأبعاد قبل إنشاء السجل.
7. إنشاء السجل والكرييتيف والتاسك داخل السيستم، ثم رفع الملف وحفظ تجهيز النشر عبر نفس الفلو المركزي.
