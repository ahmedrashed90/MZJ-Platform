# إدارة كرييتيفات الحملات والأجندات بعد الإنشاء — V1.22.3

## نطاق التنفيذ

تمت إضافة إدارة الكرييتيف من داخل تفاصيل الحملة أو الأجندة في قاعدة بيانات التسويق، مع الحفاظ على الفلو الأساسي:

- الكرييتيف مرتبط بـ Task Template وتاسك تنفيذي.
- الحملة: الكرييتيف ثم الميزانية ثم جدول النشر.
- الأجندة: الكرييتيف ثم اليوم وجدول النشر.

## إضافة كرييتيف

من تفاصيل الحملة أو الأجندة يظهر زر **إضافة كرييتيف** طبقًا لصلاحية التعديل.

- في الحملة يجب استكمال بيانات الكرييتيف، الميزانية، وجدول النشر.
- في الأجندة يجب استكمال بيانات الكرييتيف واليوم وجدول النشر.
- يتم إنشاء Task Template والتاسكات التنفيذية داخل نفس الحملة أو الأجندة.
- لا يتم إنشاء سجل حملة أو أجندة جديد.

## تعديل كرييتيف

من كارت الكرييتيف يظهر زر **تعديل** طبقًا لصلاحية التعديل.

- تعديل الميزانية أو جدول النشر فقط لا يعيد إنشاء التاسكات.
- تعديل بيانات التكليف قبل بدء التنفيذ ينشئ مراجعة جديدة للتكليف.
- إذا كان Task Template السابق معتمدًا، تصبح النسخة الجديدة **تحت المراجعة**.
- لا تنتقل بيانات النسخة المعدلة إلى التاسك التنفيذي إلا بعد اعتماد Task Template الجديد.
- يمنع تغيير بيانات التكليف بعد بدء التاسك التنفيذي، مع السماح بتعديل الميزانية وجدول النشر.
- يمنع تعديل كرييتيف تم نشره.

## سلامة البيانات

- التنفيذ داخل Transaction واحدة.
- التحقق من صلاحية تعديل الحملة أو الأجندة ونطاق وصول المستخدم.
- التحقق من وجود ميزانية للحملة ومنصة لكل بند.
- التحقق من وجود موعد نشر وتاريخ ومنصة ونوع نشر.
- التحقق من وقوع تاريخ النشر داخل فترة الحملة أو الأجندة.
- إعادة حساب تقدم الحملة أو الأجندة بعد الحفظ.
- تسجيل الإضافة أو التعديل في سجل المراجعة والتدقيق.
