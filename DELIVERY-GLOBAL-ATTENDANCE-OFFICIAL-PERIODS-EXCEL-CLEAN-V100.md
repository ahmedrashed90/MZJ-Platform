# MZJ Platform — Global Attendance Official Periods + Excel — CLEAN V100

- Base: CLEAN v98.
- No layout/button/style changes were made to the platform report pages.
- Added configurable official workday end inside attendance period settings.
- Each attendance period closes at its configured end; all open attendance is capped by the official workday end.
- With attendance enforcement enabled, sessions for periods that auto-close are revoked by the existing attendance tick.
- Login after the official workday end is allowed without creating a new attendance record or adding work hours.
- Excel export now contains a colored professional employee summary and a daily-details worksheet, including actual work hours, delay minutes, absences, partial days, off days, required/attended/missed periods.
